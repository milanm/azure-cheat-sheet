# Azure Cheat Sheet — Agent Instructions

## Data Sources for Azure Service Updates

When reviewing or updating the cheat sheet, fetch the latest Azure service updates from:

- **Azure Updates page**: https://azure.microsoft.com/en-us/updates
- **Azure Updates RSS feed**: https://www.microsoft.com/releasecommunications/api/v2/azure/rss
- **Azure Products page** (canonical list): https://azure.microsoft.com/en-gb/products/

## Update Workflow

1. Fetch the RSS feed to identify new GA launches, retirements, and rebrands since the last update.
2. Cross-reference against the README.md service listings.
3. Add newly GA services, remove fully retired services, and update renamed services.
4. Update the "Last update" date in the README header.
